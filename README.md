# 👨‍🍳 HomeChef – Recipe Discovery Web App

**HomeChef** is a modern, clean, and responsive recipe discovery app that lets users explore delicious meals with ease. Powered by a recipe API and built with modern frontend technologies, it's perfect for food lovers and aspiring chefs!

---

## 🔗 Live Demo

🍽️ Explore it live:  
👉 **[HomeChef App](https://homechef-teal.vercel.app/)**

---

## 🎯 Features

- 🔍 Search meals by name or ingredients
- 📋 View detailed recipes with ingredients & instructions
- 🍱 Get random meal suggestions
- 💻 Responsive UI for all screen sizes
- 🚀 Fast and hosted on Vercel

---

## 🛠️ Tech Stack

- **React.js** – Frontend library
- **Tailwind CSS** – Utility-first styling
- **Axios / Fetch** – API requests
- **TheMealDB API** – For meal data
- **Vercel** – Deployment platform
